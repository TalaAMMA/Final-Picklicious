# 🥒 Picklicious - E-commerce de Produits Artisanaux

Picklicious est une application full-stack de vente en ligne spécialisée dans les sels, sauces et pickles artisanaux.

## 🚀 Fonctionnalités
* **Gestion du panier** : Ajout/Suppression de produits avec calcul du total en temps réel.
* **Authentification** : Système de connexion sécurisé (JWT).
* **Base de données** : Intégration complète avec MongoDB Atlas.
* **Build optimisé** : Utilisation d'Esbuild pour des performances front-end rapides.

## 🛠️ Technologies
* **Front-end** : React, Sass, Esbuild.
* **Back-end** : Node.js, Express.
* **Database** : MongoDB.

## 📦 Installation
1. `git clone https://github.com/TalaAMMA/Final-Picklicious.git`
2. `npm install`
3. `npm run start:all`
